# ADR Campus v1.0 — First Complete Release

Version 0.7 finished the last remaining journey (Administer the Organization), so all six journeys from [stories/overview.md](../stories/overview.md) now work end to end. Version 1.0 does not add product scope. It closes out the release: fixing a correctness gap surfaced during v0.7 live QA, giving the repository an entry point, resolving the roadmap's own definition of done, and verifying the six journeys together against real infrastructure.

## Included

- Fix the membership-observation cold-start gap: a departed member's recovery window must not depend on a Maintainer having incidentally visited an administration page while that member was still active.
- A top-level `README.md` describing the project and how to run it.
- `docs/roadmap.md` closed out: v0.7 moved to Completed Releases, and the "First Complete Release" section resolved now that the condition is met.
- A full six-journey walkthrough (draft, propose, decide, discover, supersede, administer) against live Keycloak and Redis, as the roadmap's own verification bar for the first complete release.

## Deliberately Deferred

Version 1.0 does not introduce new product scope. The exclusions listed in [stories/overview.md](../stories/overview.md#first-release-boundaries) remain in effect.
